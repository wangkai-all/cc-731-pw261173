这个仓库做什么

  • 上传 行标识 / 列标识 / 数值 三元组，作为逻辑数据版保存。
  • 行列标签 独立编号；新增标签、重排行列只改变位置，不改变既有元素的业务含义。
  • 同一坐标多次出现时，导入时选择 求和 或 按来源版本取最新，不同规则生成不同数据版。
  • 显式零、显式缺测 与 没有元素 分开保存，不因稀疏压缩被删掉。
  • 空行、空列的标签保留；矩阵维度 = 标签编号数量，而非最大数值位置。
  • CSR / CSC 使用真实 indptr、indices、kinds、data 数组，转换按内存预算分批并可中断恢复。
  • 发布前核对偏移单调、索引范围、坐标唯一与逐坐标数值；未完成布局不能参与读取。
