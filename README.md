# 稀疏矩阵入仓与查询应用

上传「行标识 / 列标识 / 数值」三元组，在网页按标签查行列、做切片，并在
**CSR（按行压缩）** 与 **CSC（按列压缩）** 两种真实压缩布局之间切换。
行列标签独立编号；新增标签与重排顺序都不改变既有元素的业务含义。

只依赖 Python 标准库，无需安装第三方包，也不需要联网。

## 快速开始

```bash
python3 -m app.server --root data --port 8000
# 浏览器打开 http://127.0.0.1:8000/
```

`--root` 指定仓库目录（`repository.json` + 二进制数组 + 导出文件）。不传时默认
使用项目下的 `data/`。首次启动是空仓库。

其它入口：

| 命令 | 作用 |
| --- | --- |
| `python3 -m unittest discover -s tests -v` | 26 个端到端测试 |
| `python3 scripts/build_deliveries.py` | 从**空仓库**重建 `deliverables/` 全部交付物 |
| `python3 scripts/demo_resume.py` | 用 SIGKILL 真正杀掉转换进程，演示断点续转 |
| `python3 scripts/verify_delivery.py` | 只读取下载文件，独立复核偏移/索引/坐标/数值 |

## 网页能做什么

**导入 / 版本**
- 粘贴 CSV / TSV 三元组（`row,col,value[,source_version[,source[,kind]]]`），
  或使用四个内置样例按钮。
- 重复坐标二选一：**求和** 或 **按来源版本取最新**。同一份输入用不同规则导入，
  会生成两个独立的数据版，各自有独立布局。
- 空值 / `NA` / `null` → 显式缺测；`0` → 显式零；两者都是**存储中的真实槽位**。

**查询与切片**
- 按行标签、列标签（逗号分隔）过滤；按**当前位置区间** `lo:hi` 做切片；
  按元素类型筛选（数值 / 显式零 / 显式缺测）。
- 点查单个坐标：返回 `present=false` 表示「没有元素」，与显式零、显式缺测区分。
- 右侧同步显示该布局的 `indptr / indices / kinds / data` 原始数组。

**存储布局**
- 每个数据版可分别构建 CSR 与 CSC。转换按**内存预算**切批写入二进制数组，
  每批结束记录检查点，可暂停、恢复；服务重启后自动降级为「暂停」并保留进度。
- 右下角核对面板展示发布前的每一项检查（偏移单调、索引范围、坐标唯一、
  逐坐标数值一致、顺序规范等）。**未通过核对的布局不出现在读取路径上**。

**行列标签**
- 行列分开编号（行 `#0` 与列 `#0` 是两个不同标签）。
- 上移 / 下移重排只改显示位置；重命名只改名字；编号与存储数组不变，已发布布局仍然可读。
- **新增**标签会改变矩阵维度，已有布局会被标记失效，需要重新转换。
- 空行 / 空列在列表中带「无元素」标记，不删除，维度按标签数量计算。

**校正与对照**
- 更正单个元素（数值 / 显式零 / 显式缺测）。更正后该版本布局失效，
  重新转换并核对后才能读取。
- 「逻辑三元组 vs 存储数组」逐坐标对照，给出 5 类差异计数。
- 删除来源记录：**元素数值保留**，只移除来源归属（审计中记录影响了多少元素）。

**交付下载**
- 导出 `.sparse` 容器（UTF-8 JSON 头 + 二进制数组 + sha256 尾校验），
  可直接下载；只有通过验证的布局才允许导出。

## 目录

```
app/sparse.py        领域模型：标签、逻辑三元组、CSR/CSC 数组、转换、校验、查询、导出
app/server.py        stdlib HTTP 服务（JSON API + 静态页面）
web/                 单页前端（无框架、无构建步骤）
tests/               端到端测试
scripts/             交付构建、断点续传演示、下载文件独立复核
deliverables/        从空仓库生成的存储文件（storage/*.sparse）、清单与交付说明（README.md）
docs/DESIGN.md       存储格式与不变量
docs/OPERATIONS.md   运维、容量与故障恢复
```

## 约定速查

| 概念 | 表示 |
| --- | --- |
| 显式零 | `kind=zero`，`data=0.0`，占一个存储槽位 |
| 显式缺测 | `kind=missing`，`data=NaN`，占一个存储槽位 |
| 没有元素 | 数组里没有任何槽位，查询返回 `present=false` |
| 行/列编号 | 首次出现时分配的稳定 `label_id`，永不重用 |
| 位置 | 当前显示顺序，重排时整体重写 |
| 矩阵维度 | 行标签数 × 列标签数，与最大编号位置无关 |
| 重复坐标·求和 | 数值相加；缺测视为「无数据」；相消为 0 时保留为显式零 |
| 重复坐标·最新 | `source_version` 大者胜；同版本取后出现的一条 |
